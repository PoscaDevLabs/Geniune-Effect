🧞 Genuine

Bring macOS-style window animations exclusively to native Linux GTK applications.

Download .DEB Installer View on GitHub

Core Features

  • GTK-Only Isolation: Hooks directly into native GTK3/GTK4 apps like Nautilus and Gedit, completely ignoring browsers, Electron apps, or native ChromeOS decorations.
  • Genie Mode: Asymmetric curved suction physics morphing windows smoothly downward into your panel interface.
  • Scale Mode: Clean center-focused structural reduction transitions.
  • Dynamic Toggle: Hot-swap states instantly from any shell instance via the Genuine-Size CLI utility.

Quick Installation

Deploy the native standalone installer straight from your terminal terminal:

sudo apt update
sudo apt install ./genuine-effect_1.0.0_all.deb
gnome-extensions enable genuine@pittriverbia2.github.io

Command Usage

Run the global wrapper path binary to alter your application layout animation profiles on the fly:

# Toggles your system layout cleanly between 'genie' and 'scale' states
Genuine-Size
